NaiveCache

KV cache used during inference — stores key/value states from previous tokens
key_cache / value_cache Dict[int, Tensor]
{0: [N_kv, 4, 128], 1: ..., 27: ...} — one entry per layer
N_kv = total cached tokens | 4 KV heads | 128 head_dim
During generation denoising: KV cache is read-only (text/image context frozen)

Forward Pass Data Flow — Qwen2Model

Step-by-step tensor transformations through the model (inference, mode="gen")
1

Input: packed_query_sequence

A pre-assembled 1D tensor containing all token embeddings: [<start_img>, latent₁...latentₙ, <end_img>]
Shape: [seq_len, 3584] — e.g. [4098, 3584] for a 1024×1024 image (4096 latent + 2 bracket tokens)
2

RoPE: Compute position embeddings

rotary_emb(sequence, position_ids) → (cos, sin) each [1, seq_len, 128]
rope_theta=1M, shared across all 28 layers. Position IDs are packed (not necessarily sequential).
3

Enter layer loop (×28 Qwen2MoTDecoderLayer)

Each layer processes the full sequence. In mode="gen", tokens are routed by type.
4

Input LayerNorm (dual)

text_indexes → input_layernorm(x)  — RMSNorm(3584) for text/bracket tokens
vae_indexes → input_layernorm_moe_gen(x)  — RMSNorm(3584) for latent tokens
Output: [seq_len, 3584]
5

Attention: Q/K/V projection (expert-routed)

Text tokens: q = q_proj(x) [N_text, 3584]  →  [N_text, 28, 128]
Latent tokens: q = q_proj_moe_gen(x) [N_lat, 3584]  →  [N_lat, 28, 128]
K/V similarly: [N, 4, 128] (GQA: 4 KV heads, each shared by 7 Q heads)
Then: q_norm / k_norm (or _moe_gen variants) → RoPE rotation
6

Merge with KV Cache + Flash Attention

New K/V states are interleaved with cached K/V from previous context (text, images):
merged_key = [cached_K, new_K] indexed by packed_key_value_indexes + packed_query_indexes
flash_attn_varlen_func(Q, merged_K, merged_V, cu_seqlens_q, cu_seqlens_k, causal=False)
Output: [seq_len, 28, 128] → reshape → [seq_len, 3584]
7

Output projection (expert-routed) + Residual

Text tokens: out[text_idx] = o_proj(attn_out[text_idx])
Latent tokens: out[vae_idx] = o_proj_moe_gen(attn_out[vae_idx])
Then: x = residual + out — first residual connection
8

Post-attention LayerNorm + MLP (expert-routed) + Residual

Text: post_attention_layernorm(x) → mlp(x) — SiLU gated: down(silu(gate(x)) * up(x))
Latent: post_attention_layernorm_moe_gen(x) → mlp_moe_gen(x)
3584 → 18944 → 3584 for both paths
Then: x = residual + out — second residual connection
9

Repeat for all 28 layers

Output of layer i feeds into layer i+1. Shape stays [seq_len, 3584] throughout.
10

Final LayerNorm (dual)

text_indexes → norm(x)  — RMSNorm(3584)
vae_indexes → norm_moe_gen(x)  — RMSNorm(3584)
Output: [seq_len, 3584]
11

Output → BaseNavitOutputWithPast

Returns (packed_query_sequence, past_key_values)
The caller (Bagel) then uses lm_head for text or llm2vae for image generation on the relevant token positions.

        +forward_inference(query_seq, ..., mode, vae_idx, text_idx)
    }

    class PackedAttentionMoT {
        %% Inherits from Qwen2Attention (q/k/v/o_proj)
        +q_proj: Linear(3584, 3584, bias)
        +k_proj: Linear(3584, 512, bias)
        +v_proj: Linear(3584, 512, bias)
        +o_proj: Linear(3584, 3584)
        +q_norm: RMSNorm(128)
        +k_norm: RMSNorm(128)
        +q_proj_moe_gen: Linear(3584, 3584, bias)
        +k_proj_moe_gen: Linear(3584, 512, bias)
        +v_proj_moe_gen: Linear(3584, 512, bias)
        +o_proj_moe_gen: Linear(3584, 3584)
        +q_norm_moe_gen: RMSNorm(128)
        +k_norm_moe_gen: RMSNorm(128)
        +forward_train(packed_seq, sample_lens, mask, pos_emb, und_idx, gen_idx)
        +forward_inference(query_seq, ..., mode, vae_idx, text_idx)
    }

    class Qwen2MLP {
        +gate_proj: Linear(3584, 18944)
        +up_proj: Linear(3584, 18944)
        +down_proj: Linear(18944, 3584)
        +act_fn: SiLU
        +forward(x): down(silu(gate(x)) * up(x))
    }

    class Qwen2RotaryEmbedding {
        +rope_theta: 1000000.0
        +max_position_embeddings: 32768
        +forward(x, position_ids) → (cos, sin)
    }

    class NaiveCache {
        +key_cache: Dict[layer_idx → Tensor]
        +value_cache: Dict[layer_idx → Tensor]
        +num_layers: 28
    }

    class Qwen2RMSNorm {
        +weight: Parameter(dim)
        +eps: 1e-6
        +forward(x): x * rsqrt(mean(x²) + eps) * weight
    }

    class BaseNavitOutputWithPast {
        +packed_query_sequence: Tensor
        +past_key_values: NaiveCache
    }

Composition Summary

Qwen2ForCausalLM
├── model: Qwen2Model
│   ├── embed_tokens: Embedding(152064, 3584)
│   ├── rotary_emb:  Qwen2RotaryEmbedding(theta=1M)
│   ├── layers [0..27]: Qwen2MoTDecoderLayer
│   │   ├── self_attn: PackedAttentionMoT
│   │   │   ├── Understanding: q/k/v/o_proj, q/k_norm
│   │   │   ├── Generation:    q/k/v/o_proj_moe_gen, q/k_norm_moe_gen
│   │   │   └── Shared: flash_attn_varlen_func + RoPE + KV Cache
│   │   ├── input_layernorm / input_layernorm_moe_gen
│   │   ├── mlp: gate(3584→18944) * up(3584→18944) → down(18944→3584)
│   │   ├── mlp_moe_gen: (same dims)
│   │   └── post_attention_layernorm / post_attention_layernorm_moe_gen
│   ├── norm:         RMSNorm(3584) ← understanding tokens
│   └── norm_moe_gen: RMSNorm(3584) ← generation tokens
└── lm_head: Linear(3584, 152064) ← text output only

Total parameters per MoT layer ≈ 2 × standard Qwen2 layer
  Understanding expert: ~250M params  |  Generation expert: ~250M params
  28 layers × 500M ≈ 14B total  (7B active for any given token)
